# Меню «Файл»

## Шаг 1 — раскрытое меню

Состояние: функционально исправно, визуально требует переработки.

- Внутри контейнера меню используются четыре полноценные кнопки с собственными рамками — получается лишний второй уровень карточек.
- Ширина `150px` заставляет длинные команды переноситься и делает высоту строк неодинаковой.
- Центрированный текст и крупная жирность затрудняют быстрое сканирование.
- Вертикальное многоточие рядом с названием `Файл` конфликтует по смыслу: многоточие обозначает общие дополнительные действия, а не раскрывающийся файловый раздел.
- Действия роутера и операции с локальным YAML визуально не разделены.

## Рекомендация

- Триггер: `Файл` и стрелка вниз вместо вертикального многоточия.
- Ширина меню около `240px`, без переносов текста.
- Пункты как плоские строки без индивидуальных рамок; левое выравнивание, мягкий фон только при наведении и фокусе.
- Использовать 18px контурные иконки Tabler, уже применяемые проектом.
- Порядок: `Перезагрузить с роутера`, `История конфигурации…`, разделитель, `Загрузить YAML`, `Скачать YAML`.
- Сохранить высоту интерактивной области не меньше 40px на десктопе и 44px на сенсорных экранах.

## Ограничения

По одному скриншоту нельзя подтвердить клавиатурную навигацию, состояние фокуса и закрытие меню по Escape или клику вне области.

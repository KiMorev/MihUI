# MihUI

Локальный редактор `proxy-providers` и связей `proxy-groups/use` для Mihomo.

## Установка на роутер

MihUI ставится как отдельный локальный UI рядом с Mihomo и не занимает порт `9090`.
По умолчанию используется порт `9878`; если он занят, установщик выберет свободный порт из диапазона `9879-9899`.
Если сервер MihUI аварийно завершится, лёгкий shell-supervisor автоматически запустит его снова через 5 секунд.
На роутере нужны `python3`, `curl` или `wget`, а также `tar`. Если `python3` не найден, установщик попробует поставить его через Entware `opkg`.
Установщик скачивает пакет из GitHub Releases.

```sh
cd /tmp
curl -fL -o mihui-install.sh https://raw.githubusercontent.com/KiMorev/MihUI/main/router/install.sh
sh mihui-install.sh
```

Если роутер не может скачать пакет с GitHub, скачайте `mihui-router.tar.gz` на компьютер, запустите рядом с ним HTTP-сервер и передайте локальный URL:

```sh
cd /tmp
curl -fL -o mihui-install.sh https://raw.githubusercontent.com/KiMorev/MihUI/main/router/install.sh
MIHUI_DOWNLOAD_URLS="http://<pc-ip>:8000/mihui-router.tar.gz" sh mihui-install.sh
```

После установки откройте:

```text
http://<router-ip>:9878/
```

Если установщик выбрал другой порт, он покажет его в конце установки.

## Обновление

Кнопка `Обновить UI` проверяет свежий релиз и запускает обновление через локальный API MihUI.

```text
POST /api/update/start
```

Скрипт скачивает свежий `mihui-router.tar.gz` из GitHub Releases и заменяет файлы UI в `/opt/etc/mihui`.

## Конфиг Mihomo

По умолчанию MihUI читает и сохраняет:

```text
/opt/etc/mihomo/config.yaml
```

После сохранения MihUI пробует перезагрузить Mihomo через `http://127.0.0.1:9090`.
Переопределения можно задать в `/opt/etc/mihui/mihui.env`:

```sh
MIHUI_CONFIG_PATH="/opt/etc/mihomo/config.yaml"
MIHUI_MIHOMO_API="http://127.0.0.1:9090"
MIHUI_MIHOMO_SECRET=""
```

Для `happ://crypt*` кнопка в UI расшифровывает ссылку локально в браузере модулем из папки `happ-decryptor` и заменяет её на прямой URL.
Локальный provider adapter также умеет разобрать `incy://import` и повторить Happ landing-запрос с `User-Agent: Happ/1.0`, `x-hwid` и `hwid` query, если обычный ответ выглядит как Happ/INCY landing.

Для отдельных подписок в форме можно выбрать формат `Xray JSON`. Только такие источники проходят через локальное преобразование в Mihomo YAML; обычные подписки продолжают загружаться напрямую. Поддерживается VLESS / TCP / Reality. Обработчик запускается только во время обновления подписки, принимает не более 512 КиБ и ограничен двумя параллельными запросами; отдельного процесса и дискового кэша он не создаёт.

Перед каждым сохранением создается бэкап, хранятся последние 5.

## Защищённый DNS

Раздел `DNS-площадка` заменён на управление защищённым DNS. Перед изменениями
MihUI проверяет конфигурацию Mihomo, системный `ndnproxy`, IPv4/IPv6-путь,
свободный порт `1053` и наличие выбранной прокси-группы.

В отказоустойчивом режиме Mihomo слушает `:1053`, а DNS-запросы клиентов к
адресам роутера перенаправляются на него только при наличии короткого firewall
lease. Lease продлевается после сквозной DNS-проверки; при остановке MihUI,
Mihomo или прокси он истекает не позднее чем через 30 секунд, после чего запросы
снова обслуживает системный `ndnproxy :53`. DNS провайдера и перехват транзитных
DNS-запросов этот режим не меняет.

Имена прокси-узлов разрешаются через существующий системный DNS роутера, а
основные DoH-upstream — через выбранную группу Mihomo. Локальный резолвер
`127.0.0.1:41100` используется для коротких имён устройств и зон `.lan`,
`.localdomain`, `.home.arpa` только после успешной UDP-проверки. Эти правила
не требуют категории `private` в пользовательской базе GeoSite. Устройства
с собственным DoH/Private DNS и клиенты, использующие DNS Tailscale или явно
заданный внешний DNS-сервер, находятся вне этого перехвата; интерфейс
показывает их как исключения.

Если обнаружено несколько LAN-мостов, выберите нужные сегменты в разделе
защищённого DNS по имени интерфейса и его IP-адресам. Предварительная проверка
не переключает клиентов; выбор применяется вместе с тестовым или защищённым
режимом. Пока сегмент не выбран, системный fallback отмечается как «не проверен»,
а не как отказ DNS. Результаты предварительных проверок, включая ошибки
проверки конфигурации Mihomo, доступны в журнале и экспорте JSON.

Строгий профиль пока доступен только как предварительный план. MihUI не меняет
настройки «Игнорировать DNS провайдера» и «Перехватывать транзитные запросы» в
Keenetic/Netcraze автоматически.

## Удаление

Сначала в разделе `Защищённый DNS` выберите `Вернуться к системному DNS`.
Установщик удаления остановится без изменений, если в конфигурации ещё есть
управляемый DNS-блок MihUI.

```sh
sh /opt/etc/mihui/uninstall.sh
```

Удаление останавливает сервис, убирает `/opt/etc/mihui` и наш init-скрипт.
Логи остаются в `/opt/var/log/mihui` для ручной проверки.
